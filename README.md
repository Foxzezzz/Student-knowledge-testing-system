# Система тестирования знаний студентов

Учебное настольное WPF-приложение с демонстрационным тестом по основам C#. Пользователь последовательно выбирает один ответ на каждый из пяти вопросов и видит число правильных ответов и процент. После завершения можно начать новую попытку.

## Требования

- Windows 10/11 для запуска WPF;
- .NET SDK 9 и Git;
- доступ к NuGet при первом восстановлении пакетов.

.NET 9 выбран по условиям учебного задания; перед дальнейшей эксплуатацией нужно проверить сроки его поддержки и обновить платформу. На Linux допускается сборка Windows-проекта и выполнение тестов ядра, но не запуск окна WPF.

## Получение и запуск через Git Bash

```bash
git clone https://github.com/Foxzezzz/Student-knowledge-testing-system.git
cd Student-knowledge-testing-system
dotnet restore
dotnet build
dotnet test
dotnet run --project KnowledgeTesting.Desktop
```

В окне выберите вариант и нажмите «Ответить». После последнего вопроса появится итог; кнопка «Начать заново» создаёт новую попытку. Для ручной проверки на Windows пройдите тест, попробуйте ответить без выбранного варианта и начните повторную попытку.

## Устройство и ограничения

`KnowledgeTesting.Core` содержит банк вопросов, модель и логику попытки; `KnowledgeTesting.Desktop` - окно; `KnowledgeTesting.Tests` - тесты. Диагностические события идут через `System.Diagnostics.Trace`; для просмотра нужен listener, например окно Output отладчика Visual Studio. В журнал не записываются имена или другие персональные данные.

Это учебный демонстрационный тест: вопросы и правильные ответы доступны в коде, пользователи не идентифицируются, результаты не сохраняются после закрытия приложения. Система не подходит для защищённого экзамена.
