# Контракты взаимодействия модулей, версия 1

Контракты предназначены для реализации на этапе 3. Оба вызова локальные и синхронные; сеть, JSON и серверный API не используются.

## Протокол 1. Получение вопросов

| Пункт | Содержание |
|---|---|
| Инициатор и получатель | Сеанс тестирования → `IQuestionBank` (реализация демонстрационного банка). |
| Назначение | Получить набор вопросов для новой попытки. |
| Механизм и точка входа | Вызов `GetQuestions()` в процессе приложения. |
| Запрос | Без параметров. |
| Успех | `IReadOnlyList<Question>`: идентификатор, текст, варианты ответа, индекс правильного варианта. Это не защищённый экзаменационный банк. |
| Ошибки | Пустой набор, пустой элемент или повтор идентификатора без учёта регистра недопустимы при создании сеанса: `ArgumentException`; пустой вариант ответа отклоняется при создании модели. |
| Таймаут | Не установлен: доступ к подготовленным данным в памяти. |
| Повтор | Повторный вызов чтения допустим, сетевых повторов нет. |
| Аутентификация | Не применяется: локальный процесс без учётных записей. |
| Версия | 1; сигнатуры, документацию и тесты изменять вместе. |

Пример: `GetQuestions()` → вопрос `("q1", "Что такое C#?", ["Язык программирования", "База данных"], 0)`.

## Протокол 2. Ответ и итог попытки

| Пункт | Содержание |
|---|---|
| Инициатор и получатель | Окно WPF → `TestSession`. |
| Назначение | Принять выбор, перейти к следующему вопросу и получить результат. |
| Механизм и точка входа | `SubmitAnswer(int optionIndex)` и `GetResult()`. |
| Запрос | Нулевой индекс выбранного варианта для текущего вопроса; `GetResult` без параметров. |
| Успех | После ответа возвращаются состояние и количество отвеченных вопросов; после последнего ответа `GetResult()` возвращает число правильных, общее число и процент. |
| Ошибки | Вариант вне диапазона: `ArgumentOutOfRangeException` без перехода; ответ после завершения или запрос результата раньше завершения: `InvalidOperationException`. |
| Таймаут | Не установлен: локальное сравнение в памяти. |
| Повтор | Автоматического повтора нет: повторная отправка после успешного ответа относится уже к следующему вопросу. |
| Аутентификация | Отсутствует: локальная учебная версия. |
| Версия | 1; изменение правил требует обновления тестов и описания. |

Пример: два вопроса, ответы `0` и `1`, оба правильные → `TestResult(2, 2, 100.0)`; выбор `10` → ошибка диапазона, прогресс не меняется.

## Модели

`Question`: строковый идентификатор, текст, список вариантов и индекс правильного варианта. `AnswerProgress`: число отвеченных и признак завершения. `TestResult`: правильные ответы, общее число и процент `correct / total * 100`. Сеанс не позволяет получить итог до ответа на все вопросы.
